# QA Test Automation

---

# Philosophy

Test critical flows first.

Focus on:
- Stability
- Reliability
- Regression prevention

---

# Test Levels

## 1. Unit Tests

Test:
- Utilities
- Business logic

---

## 2. Integration Tests

Test:
- Services
- API calls

---

## 3. E2E Tests

Test:
- Login
- Workout flow
- Logging progress

---

# Automation Scope

Automate:
- Core flows
- Repeated tests

Don't automate:
- Rapidly changing UI

---

# Test Rules

- Tests must be deterministic
- No flaky tests
- Mock external calls

---

# Coverage Goal

70–80% is enough.

---

# Golden Rule

Quality > quantity of tests.
