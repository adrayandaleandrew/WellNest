# Claude Rules

## 1. Respect Architecture

Do not:

- Change folder structure randomly
- Introduce new patterns without reason
- Rewrite stable code unnecessarily

---

## 2. Avoid Overengineering

Prefer:

- Simple logic
- Minimal abstraction
- Readable code

---

## 3. Follow Existing Patterns

If project uses a pattern → follow it.

Consistency > personal preference.

---

## 4. Output Quality

Claude must:

- Write clean code
- Add comments for complex logic
- Avoid huge files
- Avoid magic numbers

---

## 5. Ask Before Major Changes

For:

- Architecture changes
- New dependencies
- Schema changes

---

# Golden Rule

Improve the codebase.  
Never make it harder to maintain.
