# Repo Standards

---

# Project Structure

- Organized by feature
- No dead code
- No unused files

---

# Naming

Files:
kebab-case

Components:
PascalCase

Variables:
camelCase

# Documentation

Update docs when:
- Changing logic
- Adding features
- Modifying architecture

---

# Dependencies

Only add if:
- Truly needed
- Maintained
- Lightweight

---

# Code Reviews

Check for:
- Simplicity
- Security
- Readability
- Performance

## 1. Always use markdown docs
Follow all docs strictly.

## 2. Branch before task
Create branch first.

## 3. Push after finishing
Push work after completion.
