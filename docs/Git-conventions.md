# Git Conventions

---

# Branching

Always branch before work.

Format:

feature/short-description  
fix/bug-name  
chore/maintenance-task

---

# Commits

Use:

feat: add workout timer  
fix: correct streak calculation  
refactor: simplify logic  
docs: update guidelines

---

# Rules

- Small commits
- One concern per commit
- Clear messages

---

# Pull Requests

- Clear description
- Link issue if exists
- Self-review before PR

---

# Never

- Commit secrets
- Push broken builds
- Force push to main

---

# Golden Rule

Clean history = professional repo.
